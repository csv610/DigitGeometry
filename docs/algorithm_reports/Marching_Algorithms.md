# Marching Cubes, Squares, and Tetrahedra

## 1. Overview
Marching algorithms are a family of techniques used in computer graphics and medical imaging to extract a surface or boundary (iso-surface) from a volumetric data set (scalar field). **Marching Squares** is the 2D version used to extract contours. **Marching Cubes** is the standard 3D version for extracting a polygonal mesh. **Marching Tetrahedra** is an alternative to Marching Cubes that avoids some of the topological ambiguities of the latter by subdividing cubes into tetrahedra.

## 2. Definitions
*   **Scalar Field ($f(x, y, z)$):** A 3D grid (voxels) where each point has a scalar value (e.g., density).
*   **Iso-surface:** A surface consisting of points where the scalar field is equal to a constant value $c$ ($f = c$).
*   **Cell:** A basic unit of the grid. In 2D, it is a square (4 nodes); in 3D, a cube (8 nodes) or a tetrahedron (4 nodes).
*   **Case Index:** A binary number generated by comparing the scalar values at each node of a cell with the iso-value.
*   **Lookup Table (LUT):** Pre-calculated configurations of triangles for each possible case index.

## 3. Theory
The core idea is to process each cell of the grid independently. For each cell:
1.  Check which nodes are "inside" ($f > c$) and which are "outside" ($f < c$) the iso-surface.
2.  Assign a bit to each node (1 for inside, 0 for outside) and combine them into a single integer (the index).
3.  Use this index to look up which edges of the cell are intersected by the surface.
4.  Interpolate the intersection point along each edge based on the scalar values at the nodes.
5.  Generate triangles (or lines in 2D) connecting these points.

### Marching Tetrahedra vs. Marching Cubes
Marching Cubes has 256 possible cases ($2^8$), which can be reduced to 15 unique configurations using symmetry. However, some cases are ambiguous, meaning different triangle configurations could be equally valid. Marching Tetrahedra subdivides each cube into 5 or 6 tetrahedra. Since each tetrahedron has only $2^4 = 16$ cases, it is much simpler and topologically consistent, though it generates more triangles.

## 4. Pseudo Code
```text
function marchingCubes(volume, isoValue)
    mesh := emptyMesh()
    for each cube in volume
        index := 0
        for each node i in cube
            if volume[node i] > isoValue
                index |= (1 << i)
        
        edges := LUT[index]
        for each triangle in edges
            p1 := interpolate(edge1, cube, isoValue)
            p2 := interpolate(edge2, cube, isoValue)
            p3 := interpolate(edge3, cube, isoValue)
            mesh.addTriangle(p1, p2, p3)
    return mesh
```

## 5. Parameters Selections
*   **Iso-value ($c$):** The threshold that defines the boundary. In medical imaging, this might correspond to bone or soft tissue density.
*   **Grid Resolution:** Finer grids result in smoother, more detailed surfaces but increase computational cost and triangle count.

## 6. Complexity
*   **Time Complexity:** $O(N)$, where $N$ is the number of cells in the grid.
*   **Space Complexity:** $O(N)$ for storing the output mesh.

## 7. Usage
*   Visualizing 3D medical scans (CT, MRI).
*   Extracting terrain or caves from noise functions (e.g., Perlin noise).
*   Fluid simulation visualization (e.g., free surface of water).
*   Representing metaballs or implicit surfaces.
