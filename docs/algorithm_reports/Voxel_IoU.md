# Voxel IoU (Intersection over Union)

## 1. Overview
Intersection over Union (IoU), also known as the Jaccard Index, is a standard metric for measuring the similarity between two sets. In the context of 3D vision and discrete geometry, Voxel IoU is used to evaluate the accuracy of a predicted voxel grid against a ground truth grid. It quantifies how well the reconstructed 3D shape matches the target shape by comparing the overlap of their occupied voxels.

## 2. Definitions
*   **Voxel Grid ($V$):** A 3D binary grid where a value of 1 (or `true`) represents an occupied space and 0 (or `false`) represents empty space.
*   **Intersection ($A \cap B$):** The set of voxels that are occupied in both grid $A$ and grid $B$.
*   **Union ($A \cup B$):** The set of voxels that are occupied in either grid $A$, grid $B$, or both.
*   **IoU Score:** The ratio of the size of the intersection to the size of the union, ranging from 0.0 (no overlap) to 1.0 (perfect match).

## 3. Theory
The IoU score is defined mathematically as:
$$IoU(A, B) = \frac{|A \cap B|}{|A \cup B|}$$
In a discrete voxel grid, this is computed by counting the individual voxels.
*   $|A \cap B| = \sum_{i,j,k} [V_A(i,j,k) = 1 \text{ and } V_B(i,j,k) = 1]$
*   $|A \cup B| = \sum_{i,j,k} [V_A(i,j,k) = 1 \text{ or } V_B(i,j,k) = 1]$

### Relation to Dice Coefficient:
The Dice coefficient (F1-score) is another common metric related to IoU by the formula:
$$Dice = \frac{2 \cdot IoU}{1 + IoU}$$
IoU is generally considered more stringent than the Dice coefficient.

## 4. Pseudo Code
```text
function calculateVoxelIoU(gridA, gridB)
    intersectionCount := 0
    unionCount := 0
    
    // Grids must have the same dimensions
    for i from 0 to depth-1:
        for j from 0 to height-1:
            for k from 0 to width-1:
                occupiedA := gridA[i,j,k]
                occupiedB := gridB[i,j,k]
                
                if occupiedA and occupiedB:
                    intersectionCount += 1
                
                if occupiedA or occupiedB:
                    unionCount += 1
                    
    if unionCount == 0:
        return 1.0 // Both shapes are empty
        
    return intersectionCount / unionCount
```

## 5. Parameters Selections
*   **Grid Resolution:** The resolution of the voxel grid (e.g., $32^3, 128^3$) affects the precision of the IoU. Lower resolutions might hide fine-scale errors.
*   **Occupancy Threshold:** If the grids contain probabilities (from a neural network) rather than binary values, a threshold (e.g., 0.5) must be chosen to convert them to binary before computing IoU.
*   **Alignment:** Grids must be perfectly aligned in world space for the metric to be meaningful.

## 6. Complexity
*   **Time Complexity:** $O(N^3)$, where $N$ is the resolution of one side of the voxel grid. Every voxel must be compared once.
*   **Space Complexity:** $O(1)$ auxiliary space if the comparison is done in-place, or $O(N^3)$ to store the grids.

## 7. Usage
*   **3D Object Detection:** Evaluating the accuracy of 3D bounding boxes or shapes predicted by a model.
*   **Semantic Segmentation:** Measuring the overlap of class-specific voxel regions.
*   **Medical Imaging:** Comparing manual segmentations of organs or tumors with automated ones.
*   **Generative Modeling:** Assessing the quality of 3D shapes generated by GANs or Variational Autoencoders.
